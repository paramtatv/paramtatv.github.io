Two playgrounds in your browser tab: Brihaspati and MantraSutra

2026-10-14 · Paramtatva sassemblybrihaspatimantrasutrawebassemblysanskrit

संस्कृतम् हिन्दी

Two of our projects now live as pages you can open and use straight away, with nothing to install. Brihaspati is a notebook for Sassembly, our Sanskrit-native RISC-V assembly language. MantraSutra is a workbench for formulas and verse. Both do their real work inside the browser tab.

Brihaspati: a Sassembly notebook

Open paramtatv.github.io/brihaspati, write a cell and press चालय (Run). Here is what happens next:

  1. The cell is compiled by the self-hosted Sassembly compiler, Sassembly compiling Sassembly. The compiler image is 923,042 bytes.
  2. The compiler runs on yantra, our RV64 interpreter, compiled to WebAssembly. That module is 219,508 bytes.
  3. The program the compiler emits then runs on the same interpreter, in a background worker of the same tab.

The interpreter starts with an empty import object. It is given no system call, no clock and no socket. The compiler, the interpreter and the native runner are each pinned by sha256.

A cell looks like this. It prints the byte 88 (X) and returns 7:

मण्डलम् शृङ्खला ॥
आयातः अष्टक ।

सार्वजनिक वृत्तिः स्वपरीक्षास्वप्रतिबिम्बम् ददाति न६४ आदि
    चरः क ॱॱ अङ्कः अन्तः न६४ भवति ० ।
    चरः अवगणना ॱॱ न६४ भवति अष्टकॱमुद्रणम् ८८ ।
    प्रत्यागमनम् ७ ।
इति

The names are words. अष्टकॱमुद्रणम् prints an octet and प्रत्यागमनम् returns. Compiling this cell takes 73,268,811 guest instructions and running it takes 44.

The browser result equals the native result. For every sample cell, the emitted program's sha256, the output, the status, the instruction counts, the guest RAM and the heap high-water mark are identical in the browser and in a native run. A test checks all 19 sample cells, and before it starts it confirms that it really does catch a flipped field. We also checked the live page. We opened the अङ्कगणितम् (arithmetic) example and pressed सर्वं चालय (Run all) in headless Chrome. All eight code cells compiled and ran, and every one was marked रक्षितेन समम्: equal to the saved native output. The whole notebook took 69 seconds.

The notebook has:

  • code cells and Markdown note cells, which you can edit, run one at a time or all together, add, delete and move;
  • notebooks that open and save as plain-text .isas files, with a badge on any saved result that a re-run does not reproduce;
  • a sidebar library of the notebooks saved in your browser;
  • four example notebooks: arithmetic, arrays and output, refusals, and images;
  • refusals named in Sanskrit. Checked overflow, a write at −1, a read past the end and division by zero stop with statuses 860, 861, 853 and 862, and each one is shown by its Sanskrit name;
  • an interface that is Sanskrit-first, with English and Hindi toggles.

Every file the page uses (its code, the compiler image and the WebAssembly module) is served from the page's own site. The only other requests are for its web fonts. We are building toward live sessions in which cells share one running image.

MantraSutra: formulas and verse, computed in the tab

mantrasutra.github.io runs a vendored Pyodide with a Python and mpmath engine directly in the browser. It is the same engine the project tests against. We loaded all five pages in headless Chrome, and every request went to mantrasutra.github.io itself. In that run the engine was ready about seven seconds after the page opened.

  • Editor. Type x^2/(1+e^x) and the page shows the rendered LaTeX \frac{x^{2}}{1 + e^{x}}, the canonical सूत्र string and an English gloss: "the square of x divided by the sum of 1 and the power, with exponent x, of e." A button round-trips the formula back to its canonical form. Input it cannot read gets a named refusal instead of a guess.
  • Mantra. Paste a verse in Devanagari or IAST. We chose Bhagavadgītā 1.1 from the examples, and the page identified the metre as अनुष्टुभ् (श्लोक). It split the verse into four pādas of eight syllables each and marked every syllable guru or laghu, giving the reason (a long vowel, a following conjunct, anusvāra or visarga). It counted the mātrās of each pāda (15, 12, 13 and 10), gave each pāda's prastāra index out of 256, and listed the attested readings of each word. The weights follow Piṅgala's Chandaḥśāstra. A link draws the weight curve in the Explorer.
  • Functions and Explorer. Domain packs of textbook formulas are evaluated by the engine and plotted as curves, heat maps, surfaces, domain colouring and sphere views.

One notebook format for both

MantraSutra's Mantra and Editor pages keep a history of your runs in the browser, and they save and export it as .isas, the same notebook format Brihaspati uses. The MantraSutra site uses byte-identical copies of Brihaspati's .isas reader and writer, so a file saved on one page opens on the other.
